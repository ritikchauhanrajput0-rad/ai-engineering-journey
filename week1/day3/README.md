# Week 1 - Day 3: Token Usage in Groq API

## Objective

Learn how to measure token usage in LLM API responses and understand how different prompts affect the number of tokens consumed.

---

## Concepts Learned

### 1. Response Usage

The Groq API returns a `usage` object that provides information about token consumption for every request.

```python
usage = response.usage
```

---

### 2. Types of Tokens

- **Prompt Tokens**
  - Tokens used by the input prompt sent to the model.

- **Completion Tokens**
  - Tokens generated by the AI in its response.

- **Total Tokens**
  - Sum of prompt tokens and completion tokens.

```python
print(usage.prompt_tokens)
print(usage.completion_tokens)
print(usage.total_tokens)
```

---

### 3. Token Consumption

Different prompts consume different numbers of tokens.

Examples:

- Short greeting → Low token usage
- Detailed explanation → Medium token usage
- Long essay request → High token usage

This is important because API cost and model limits are based on tokens rather than characters.

---

## Implementation

Built a Python program that:

- Loads the API key from a `.env` file.
- Connects to the Groq API.
- Sends multiple prompts.
- Retrieves the `usage` object.
- Prints token statistics for every prompt.

---

## Experiments Performed

I tested the following prompts:

1. Hi, how are you?
2. Explain time travel in detail.
3. Write a 1000-word essay on machine learning.

### Observation

- Short prompts required fewer prompt and completion tokens.
- Longer prompts resulted in significantly higher completion tokens.
- Total token usage increased with the complexity and length of the requested response.

## Key Takeaways

- LLM APIs charge and limit usage based on tokens.
- The `usage` object helps monitor API consumption.
- Longer prompts generally consume more completion tokens.
